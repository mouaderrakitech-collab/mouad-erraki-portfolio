Copier le contenu de cette archive dans une copie du dossier original, en conservant le dossier assets original. index.html est le point d’entrée. Les CSS et JS sont séparés; les images intégrées ont été extraites. Les médias externes listés dans ASSETS-MANQUANTS.txt ne sont pas fournis. Lancer python -m http.server 8000 puis http://localhost:8000. Les dépendances CDN et le formulaire existant nécessitent Internet.
